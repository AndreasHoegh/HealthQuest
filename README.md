# 🏆 HealthQuest - Gamified Patient Wellness Platform

Full-stack application that gamifies patient healthcare through daily quests, points, and achievements.

## 🚀 Tech Stack

**Backend:**

- .NET 8 Web API
- Entity Framework Core
- JWT Authentication
- In-memory Database
- Swagger/OpenAPI

**Frontend:**

- Angular 17 (Standalone Components)
- TypeScript
- RxJS
- Responsive CSS

## ✨ Features

- 🔐 JWT Authentication
- 🎮 Daily Quest System (Medication, Exercise, Health Tracking)
- 🏆 Points & Leveling System
- 🔥 Streak Tracking
- 📊 Progress Monitoring
- 📱 Responsive Design
- ⚡ Real-time Updates

## 🏃 Quick Start

### Prerequisites

- .NET 8 SDK
- Node.js 18+

### Run Backend

```bash
cd backend/HealthQuest.API
dotnet run
```

### Run Frontend

```bash
cd frontend/healthquest-app
npm install
npm start
```
